## 🚀 About the Project
**NextBot** is an intelligent **AI-powered assistant** for ERPNext that helps users ask questions and get instant, accurate answers.  
It aims to simplify ERPNext usage by providing **guidance, explanations, and insights** directly inside your workflow.  

> ⚠️ **Note:** This project is at an early stage and currently under active development.  

---

## ✨ Planned Features
- 💬 Ask **natural language questions** about ERPNext  
- 📊 Get **instant insights & explanations**  
- 🧩 Seamless ERPNext integration  
- 🌐 Multi-language support  
- 🤝 Community-driven enhancements
